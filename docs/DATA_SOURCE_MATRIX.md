## Operational onboarding requirements

For every connected source capture provider, endpoint/version, terms review date, authorized uses, geography, reporting lag, retention/deletion rule, redisplay/training permissions, quota/cost, freshness and fallback. These fields belong in a source registry and ingestion-run lineage; they are not currently represented as authoritative tables.
